# Making my personal page

Today I started putting this page together. I wanted somewhere that feels more like me, with a black and pink style and a bit about who I am.

## How it came together

The first version was a bit too gothic for what I wanted, so I went with a simpler egirl style: mostly black, softer pink details, a few hearts, and a clean, readable font.

I added matching Roblox and Steam profile cards next to the about me, changed the bio to focus more on my interests, and set up this devlog so I can share updates here.

## Still sorting out

The Spotify and game cards are set up, but the presence bot is down at the moment. They’ll show my activity when that’s available again.

For now, I’m happy with the direction this is going. More updates when there’s something to share.
